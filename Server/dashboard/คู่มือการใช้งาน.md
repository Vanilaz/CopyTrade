## การติดตั้งบนเครื่อง (Development)

### Prerequisites

- **Node.js** >= 18
- **npm** >= 9

### ขั้นตอน

```bash
# 1. Clone repo
git clone <your-repo-url>
cd CopyTrade

# 3. ติดตั้ง Dependencies
cd dashboard
npm install

# 4. สร้างไฟล์ .env
# สร้างไฟล์ .env ในโฟลเดอร์ d:\CopyTrade\server\dashboard

# 5. Build และเริ่มระบบ
npm run build
npm start
# → Dashboard จะรันที่ http://localhost:8080
```

### Dev Mode

- Dashboard dev server รันที่ **port 3000** พร้อม hot-reload
- Backend server รันที่ **port 8080**
- Vite proxy จะ forward `/api/*` จาก 3000 → 8080 อัตโนมัติ
- WebSocket จะต่อตรงไปที่ browser host (ในกรณี dev → ต้องมี server ที่ 8080)

## การ Deploy บน Render.com

### แบบ Auto (แนะนำ)

1. Push code ขึ้น GitHub
2. เข้า [Render Dashboard](https://dashboard.render.com)
3. กด **New → Blueprint** → เลือก repo
4. Render จะอ่าน `render.yaml` แล้วสร้าง service อัตโนมัติ
5. ตั้งค่า **Environment Variables** ใน Render Dashboard:
   - `AUTH_TOKEN` — Token สำหรับ EA authentication
   - `DASHBOARD_PASSCODE` — Passcode สำหรับเข้า dashboard
   - `TELEGRAM_BOT_TOKEN` — (optional) Telegram alerts
   - `TELEGRAM_CHAT_ID` — (optional) Telegram chat ID

### Build Process บน Render

```
render.yaml → buildCommand:
  cd Server && npm ci --production && cd dashboard && npm ci && npm run build
```

สิ่งที่เกิดขึ้น:
1. `npm ci --production` — ติดตั้ง server deps (ws)
2. `cd dashboard && npm ci` — ติดตั้ง React deps
3. `npm run build` — Build React → `dashboard/dist/`
4. Server จะ serve ไฟล์จาก `dashboard/dist/` อัตโนมัติ

## การอัปเดต (Online Update)

### ✅ วิธีที่ 1: Auto Deploy (เร็วที่สุด)

เพียงแค่ **push code ขึ้น GitHub** — Render จะ auto-deploy ให้:

```bash
# แก้ไขไฟล์ที่ต้องการ...
git add -A
git commit -m "update: ชื่อการอัปเดต"
git push origin main
```

Render จะ:
1. ดึง code ใหม่
2. รัน `npm ci` + `npm run build` (React)
3. Restart server ด้วย build ใหม่
4. **Zero-downtime** (สร้าง instance ใหม่ก่อนปิดตัวเก่า)

> ⏱️ ใช้เวลาประมาณ **2-5 นาที** จนกว่าจะ live

### วิธีที่ 2: Manual Deploy

1. เข้า [Render Dashboard](https://dashboard.render.com)
2. เลือก service `copytrade-relay`
3. กด **Manual Deploy → Deploy latest commit**

### วิธีที่ 3: Build เฉพาะ Dashboard (ไม่ restart server)

ถ้าแก้แค่ UI ไม่ได้แก้ server.js:

```bash
cd Server/dashboard
npm run build
```

แล้ว push `dist/` ขึ้น git (ไม่แนะนำ — ใช้วิธีที่ 1 ดีกว่า)

## คู่มือการใช้งาน Dashboard

### 🔐 Login

- เปิด URL ของ Render service เช่น `https://copytrade-relay.onrender.com`
- ใส่ **Passcode** ที่ตั้งไว้ใน `DASHBOARD_PASSCODE`
- Passcode จะถูกเก็บใน browser (localStorage) ไม่ต้องกรอกซ้ำ

### 📊 Tab: Overview

| ส่วน | รายละเอียด |
|------|------------|
| **Hero Stats** | Master count, Slave count, Total Floating P&L, Total Executions, Uptime |
| **Master Accounts** | แสดงรายชื่อ Master ที่เชื่อมต่อ พร้อม Balance, Equity, Floating P&L |
| **Slave Accounts** | แสดง Slave ที่ follow master พร้อมสถานะ |
| **Execution Terminal** | Log ของ signal ทั้งหมด (OPEN, CLOSE, MODIFY) แบบ real-time |

### 🏦 Tab: Performance

| ส่วน | รายละเอียด |
|------|------------|
| **Summary Cards** | Total AUM, Avg Win Rate, Total Trades |
| **Performance Table** | ตาราง full-featured: Balance, Today/Week/Month P&L, Win Rate + bar, Max Drawdown, Current DD |
| **Reset Stats** | ปุ่มรีเซ็ต drawdown/win-loss (ใช้ด้วยความระวัง!) |

### 🖥️ Tab: Monitor (ใหม่!)

| ส่วน | รายละเอียด |
|------|------------|
| **📈 Equity Chart** | กราฟ equity/balance ย้อนหลัง 24 ชม. แสดงทุก account ในกราฟเดียว |
| **🔄 Sync Monitor** | เปรียบเทียบ positions Master ↔ Slave, แสดง SYNCED / OUT-OF-SYNC + missing symbols |
| **⚠️ Risk Dashboard** | Margin Usage %, Free Margin, Margin Level, Exposure per Symbol พร้อม risk meter |
| **📋 Position Grid** | แสดง Open Positions ทั้งหมด แยกตาม account: Symbol, Direction, Lots, Open Price, P&L, Swap |

### 📜 Tab: History

| ส่วน | รายละเอียด |
|------|------------|
| **Trade History Table** | ตาราง closed trades: Time, Account, Symbol, Type, Lots, Fill Price |

## ✨ ขีดความสามารถ Live Dashboard (v3.0.2)

ระบบ Dashboard รุ่นใหม่ถูกออกแบบมาให้เป็น **"Live Terminal"** เต็มรูปแบบ:

1. **TradingView Experience**: กราฟ Equity ถูกปรับให้มีความละเอียดระดับ **1 วินาที** (จากเดิม 10-30 วินาที) ทำให้คุณเห็นความเคลื่อนไหวของพอร์ตได้สดที่สุด
2. **Value Tickers**: ตัวเลขกำไร/ขาดทุนจะมีการ "กระพริบ" สีเขียว/แดง เมื่อมีการขยับของราคาเหมือนบนกระดานเทรดจริง
3. **Neural Relay Architecture**: ระบบส่งข้อมูลผ่าน WebSocket แบบรัว (5 ครั้งต่อวินาที) เพื่อให้แน่ใจว่าค่าที่ปรากฏบนหน้าจอคือค่าปัจจุบันของตลาด
4. **Auto-Reconnection**: ระบบมีวงจรเชื่อมต่อใหม่เองใน 3 วินาทีหากเซิร์ฟเวอร์หลุด คุณไม่จำเป็นต้องกด Refresh หน้าจอเองอีกต่อไป

## Troubleshooting

### Dashboard ขึ้น "SYSTEM OFFLINE"

- **สาเหตุ**: WebSocket ต่อ server ไม่ได้
- **แก้ไข**: ตรวจสอบว่า server.js รันอยู่ที่ port 8080, ถ้าใช้ dev mode ต้องรัน server แยก

### Login ไม่ผ่าน

- **สาเหตุ**: Passcode ไม่ตรงกับ `DASHBOARD_PASSCODE` ที่ตั้ง
- **แก้ไข**: ตรวจสอบ env var บน Render หรือ local env

### Sync Monitor แสดง "No slaves to monitor"

- **สาเหตุ**: ยังไม่มี Slave EA เชื่อมต่อ
- **แก้ไข**: ปกติ — จะแสดงเมื่อ slave EA เชื่อมต่อแล้ว

### กราฟ Equity ว่างเปล่า

- **สาเหตุ**: Server เพิ่งเริ่มทำงาน ยังไม่มี snapshot
- **แก้ไข**: รอ 30 วินาที server จะเก็บ equity snapshot อัตโนมัติ

### Build ล้มเหลวบน Render

```bash
# ตรวจสอบ build ใน local ก่อน
cd Server/dashboard
npm ci
npm run build
# ถ้ามี error จะแสดงที่นี่
```

### ต้องการกลับไป Dashboard เก่า

- ไม่สามารถทำได้แล้ว (ถูกลบออก)
- ถ้าจำเป็น ดึงจาก git history: `git checkout HEAD~1 -- Server/public/dashboard.html`
